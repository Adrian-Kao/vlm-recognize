# 真人攝影機驗收清單

目前自動測試使用明確標示的合成骨架。以下項目必須在實際裝置完成後，才可宣稱真人 camera／MediaPipe 通過。

## 環境紀錄

記下日期、裝置、OS、瀏覽器版本、相機解析度、光線、MediaPipe delegate、模型 SHA-256、每類樣本數。使用 `npm run setup:assets && npm run dev`，只在 localhost 或 HTTPS 開啟。

## 權限與生命週期

- 拒絕權限時顯示可採取行動的訊息；重播頁仍可使用。
- 允許後只要求攝影機、不要求麥克風。
- 切到 3D 頁、按停止、重新整理時，相機指示燈熄滅。
- 模型檔暫時移開時顯示載入失敗，不出現假成功。

## M1 新增與資料

- 錄製一段 0.5–8 秒動作，確認 overlay 與左右手文字。
- 切換鏡像預覽後再錄同動作；確認名稱／辨識方向不被鏡像開關改寫。
- 儲存後重新整理，確認樣本、raw frames 時長與 3D 預覽仍存在。
- 同名追加快、慢與不同幅度各 3–5 份。雙手保持分離清楚，不以交叉遮蔽作初始成功條件。

## M2 3D

- 用名稱搜尋，確認播放的是剛才錄下的真實 clip，不是預設動畫。
- 檢查向左／向右 root trajectory、握拳／張開、雙手相對位置。
- 檢查正面／側面／背面、自由旋轉、暫停、拖曳、0.25–2× 與循環。
- 確認 1× 實際播放時間與裁切時長相符；大幅前後移動時接受 UI 所述的全域深度限制。

## M3/M4 辨識

每類用未存入模板的新示範測試，記錄原始次數：

- 相同手形向左滑／向右滑。
- 順時針／逆時針畫圈。
- 先握拳再張開／先張開再握拳。
- 同動作快／慢版本。
- 雙手分開到靠近／靠近到分開。
- 未登錄動作、無手、日常調整姿勢、短暫遮蔽。

記錄正確類別、預測類別、Unknown／Ambiguous／Invalid、每類召回原始分子分母、未知誤接受數、無動作每分鐘誤觸發、end-hold 等待與總延遲。不要以模板自己比對自己的結果當準確率。

## M5 資料交換

- 匯出，清除，重新匯入；確認名稱、左右手、點位、時長與播放一致。
- 改名後舊動畫不變；刪代表樣本後仍選到存在的樣本。
- 匯入錯誤版本、缺 21 點或過大檔案，確認原記憶庫未變。
